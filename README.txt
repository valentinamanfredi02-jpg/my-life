COME PUBBLICARLA GRATIS CON GITHUB PAGES
1. Crea o accedi a un account GitHub.
2. Crea un nuovo repository pubblico chiamato my-life.
3. Carica TUTTI i file e le icone contenuti in questa cartella nella cartella principale del repository.
4. Vai in Settings > Pages.
5. In Build and deployment scegli Deploy from a branch, branch main e folder / (root), poi Save.
6. Attendi la pubblicazione: GitHub mostrerà un indirizzo https://TUO-UTENTE.github.io/my-life/.
7. Apri quell'indirizzo in Safari sul tuo iPhone, premi Condividi e poi Aggiungi alla schermata Home.

NOTE
- L'app salva i dati localmente nel browser/dispositivo. Non sincronizza automaticamente tra dispositivi.
- Usa Esporta i miei dati nelle Impostazioni per creare una copia JSON.
- Le notifiche push non sono incluse in questa prima versione.
- Il calcolo delle date dell'anello è un promemoria organizzativo configurabile, non un'indicazione medica. Inserisci la durata prevista dal foglio illustrativo del tuo specifico prodotto.
- Il font può usare Google Fonts se c'è connessione; l'app resta utilizzabile anche senza.
